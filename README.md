# M3-Practical-Solutions

Python implementations, numerical methods, and structured datasets for Applied Mathematics (M3) lab practicals.

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Rohan-Korake/M3-Practical-Solutions.git
```

### 2. Navigate to the Project Directory

```bash
cd M3-Practical-Solutions
```

### 3. Run a Practical Script

**Windows (CMD / PowerShell):**

```cmd
python fileName.py
```

**macOS / Linux (Terminal):**

```bash
python3 fileName.py
```
